Data Analytics Internship – Task 27 (Salesperson Performance Analysis)

This repository contains my submission for Task 27 of the Data Analytics Internship.

Dataset - Sample Superstore Dataset

Objective - The objective was to compare performance using sales, profit, growth, average order value, and other KPIs while considering territory differences.

Note on Dataset - The Sample Superstore Dataset does not contain a Salesperson column. Therefore, Region was used as the performance/territory dimension for the analysis instead of creating or assuming salesperson data.

Tools Used
1. DB Browser for SQLite
2. Microsoft Excel
3. Power BI
4. GitHub

Regional Performance Analysis
1. Used the Sample Superstore Dataset for the performance analysis.
2. Used SQL to calculate sales, profit, profit margin, total orders, average order value, yearly sales, growth, and performance rankings.
3. Used Excel to organize regional performance metrics, calculate sales and profit rankings, and analyse yearly sales growth.
4. Created a yearly sales line chart to compare regional sales trends from 2014 to 2017.
5. Created recommendations based on sales, profit, growth, average order value, and profit margin.
6. Created a Power BI dashboard to visualize regional performance using multiple KPIs and filters.

Key Results
1. West ranked first in both Total Sales and Total Profit.
2. West had the highest Profit Margin at approximately 14.94%.
3. West had the highest Average Order Value at approximately 882.55.
4. West recorded the highest sales growth at approximately 69.14%.
5. East recorded approximately 65.59% sales growth.
6. South recorded the lowest sales growth at approximately 18.35%.
7. Central had the highest number of orders but ranked fourth in profit, showing that order volume alone is not enough to evaluate performance.

Recommendations
1. Maintain the strong performance of the West region and identify successful strategies that can be applied to other regions.
2. Continue growth-focused strategies in the East region while maintaining profitability.
3. Focus on improving profitability and average order value in Central rather than only increasing order volume.
4. Investigate the lower growth of South and develop targeted strategies to improve its performance.

Conclusion
Regional performance was successfully analyzed using multiple KPIs including sales, profit, growth, average order value, profit margin, and order volume. The analysis showed that revenue alone is not sufficient for evaluating performance and that territory differences and multiple performance indicators should be considered for a fair comparison.
